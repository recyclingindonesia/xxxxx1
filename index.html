Apa yang bisa dilakukan di Web?

  • Embed Map: Menampilkan peta interaktif secara gratis menggunakan Iframe (seperti di atas).
  • Deep Linking: Membuat tombol yang langsung membuka navigasi di aplikasi Google Maps (sangat berguna untuk petunjuk arah ke toko/kos).
  • Google Maps API: Jika menggunakan API Key, Anda bisa menambahkan marker khusus, mengubah style peta, atau mencari rute perjalanan secara dinamis.
  • Static Maps: Menampilkan peta dalam bentuk gambar (hemat kuota data untuk user).
